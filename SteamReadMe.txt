[h1]Quasimorph ImplantIndicator[/h1]


[h1]Implant indicator[/h1]

Recolors the implant indicator in creature and corpse inspection windows when the inspected creature has one or more installed implants.

[h1]Legacy Note[/h1]

This was previously part of the Red's Opt-in Mod Pack.

[h2]Configuration[/h2]

The mod can be configured using the Mods button on the main menu, or directly in the config file.

The configuration file is created on the first game run at [i]%AppData%\..\LocalLow\Magnum Scriptum Ltd\Quasimorph_ModConfigs\ImplantIndicator\config.json[/i].
